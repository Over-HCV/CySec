\porque{cómo usar esta plantilla}{%
  Cada pregunta del enunciado está transcrita como \texttt{\textbackslash pregunta}
  seguida de un entorno \texttt{respuesta} vacío. Escribe dentro del entorno; mientras
  esté vacío aparece la caja naranja y el \texttt{.log} deja un warning
  «Respuesta pendiente». En los bloques de selección múltiple marca tu elección
  cambiando \texttt{\textbackslash opcion} por \texttt{\textbackslash opcion*}
  (admite varias, el enunciado dice «1 o más respuestas válidas»).
  Estas notas naranjas desaparecen con \texttt{make ws-01 FINAL=1}.%
}
