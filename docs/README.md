# Docs

Documentación del repositorio en markdown: decisiones, guías de uso y notas que
no pertenecen a un proyecto concreto.

Lo que **no** va aquí:

- Entregables del curso → `../latex/workshops/`
- Apuntes teóricos → `../theory/`
- Material crudo del profesor → `../notes/`
- Documentación de una aplicación → su propio `README.md` dentro de `../apps/<app>/`
