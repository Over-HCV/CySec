## 4. Inyección SQL

### 4.1 Introducción

Muchos desarrolladores web no son conscientes de cómo las consultas SQL pueden ser manipuladas, y asumen que una consulta SQL es una orden fiable.

Esto significa que las consultas SQL son capaces de eludir controles de acceso, evitando así las comprobaciones de autenticación y autorización estándar, e incluso algunas veces, que las consultas SQL podrían permitir el acceso a comandos al nivel del sistema operativo del equipo anfitrión.

La inyección directa de comandos SQL es una técnica donde un atacante crea o altera comandos SQL existentes para exponer datos ocultos, sobrescribir los valiosos, o peor aún, ejecutar comandos peligrosos a nivel de sistema en el equipo que hospeda la base de datos. Esto se logra a través de la práctica de tomar la entrada del usuario y combinarla con parámetros estáticos para elaborar una consulta SQL.

### 4.2 Ejercicio Inyección SQL Activa Usando Sqlmap

Realice una búsqueda avanzada usando Google: `inurl: .asp?id`

Para el ejercicio puede hacer uso de una URL que identifique en la búsqueda, o puede hacer uso de cualquiera de las siguientes URLs:

- http://testphp.vulnweb.com/listproducts.php?cat=1
- https://www.china-mould.com/cn_Contact.asp?ID=12

Acceda a Kali a la opción `APLICACIONES / 04 - Evaluación de Base de Datos / sqlmap`.

Estando en la línea de comando ejecute la opción de ayuda de SQLMAP:

```bash
sqlmap -h
```

- [ ] Describa las opciones que pueden ser usadas por esta herramienta.

Ahora procedemos a realizar el escaneo a la URL que se identificó; para ello ejecute la siguiente sentencia:

```bash
sqlmap -u "<URL_SITIO_WEB>"
```

Una vez se ejecute el comando `sqlmap` comenzará a ejecutar el escaneo a la URL. En caso de encontrar parámetros inyectables desplegará la siguiente salida indicando la versión del Web Server y de la Base de Datos.

Teniendo en cuenta las opciones que se desplegaron con la ayuda de SQLMAP, se solicita se obtenga la siguiente información (por favor adjunte la evidencia respectiva):

- [ ] Versión del Motor de la Base de Datos.
- [ ] Usuario Actual de la Base de Datos.
- [ ] Base de datos Actual (instancia actual).
- [ ] Hashes de los password de usuarios de la instancia de base de datos actual.
- [ ] Esquema de tablas de la Base de datos actual.
- [ ] Columnas de una de las tablas de la Base de datos actual.
- [ ] Hacer un volcado del contenido de una de las tablas de la base de datos.
