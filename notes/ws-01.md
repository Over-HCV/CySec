## AAA: 3 atributos clave

| Concepto         | Definición                                                   |
| ---------------- | ------------------------------------------------------------ |
| Autenticación    | Validación de la identidad de un usuario o proceso           |
| Autorización     | Validación de los permisos otorgados a un usuario o proceso  |
| Accounting       | Registro de la actividad de un usuario o proceso             |

Versión en inglés (diagrama):

- **Authentication** — Who is the user and does he have valid credentials?
- **Authorization** — What can the user do and does he have the authority?
- **Auditing** — What did the user do and is it being recorded?

## Authentication

- **e-Authentication:** process of establishing confidence in user identities electronically in an information system.
- **Authenticator Management:** processes and procedures for issuing and revoking authenticators. Aplica a hardware y software.

Tipos de autenticadores:

- Passwords
- Tokens
- Biometrics
- Public Key Infrastructure (PKI) certificates
- Key cards
